# Agent instructions

Before starting any non-trivial task in a repository that references this skills library:

1. Read [`INDEX.md`](INDEX.md).
2. Select only the skills whose `when_to_use` (and skill `description` frontmatter) match the current task. Listed skills are eligible, not mandatory for every request.
3. Open each selected skill's `SKILL.md` and follow it. Load referenced files inside that skill only when needed.
4. Prefer the smallest relevant set (usually 1–3 skills).
5. At the start of your reply (or in your plan), state which skills you loaded and why.
6. Do not invent credentials, hosts, or private project context from these generic skills.
7. For `ui-ux-pro-max` and brand `DESIGN.md` bodies under `awesome-design-md`, follow the pointer/SOURCE notes and fetch the canonical public upstream content when required.

If nothing in the index matches, proceed with normal engineering judgment and say that no skill was loaded.
