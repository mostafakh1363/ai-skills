# استفاده از Mycel

نسخه 0.22.0 معمولاً در `~/.local/share/mycel` (یا `$MYCEL_HOME`) نصب می‌شود.

شروع:

```sh
node ~/.local/share/mycel/mycel.mjs start
```

آدرس: http://127.0.0.1:4317

در چت پروژه به Codex بگو: «با مهارت mycel-project-map نقشه فارسی این پروژه را بساز؛ اول بخش‌های اصلی، بعد مسیرهای مهم با فایل‌های مرتبط.»

روی بلوک دوبار کلیک کن تا زیرنقشه باز شود؛ Esc برای برگشت است. سطح نمایش را با اسلایدر تغییر بده. یک بلوک را انتخاب کن و در چت بگو «این بخش را توضیح بده». بعد از ویرایش نقشه Finish edits را بزن و در چت بگو «تغییرات نقشه را بخوان»؛ در این اتصال، دکمه به‌تنهایی چت بسته یا بیکار را فعال نمی‌کند.

بعد از تغییر کد از Codex بخواه نقشه را هم به‌روز کند. تشخیص تغییر فایل فقط احتمال قدیمی‌شدن را مشخص می‌کند. سبزشدن بلوک باید نتیجه تست واقعی باشد. خود Mycel به کلید API نیاز ندارد؛ مصرف Codex تابع اشتراک یا تنظیمات خود Codex است.

توقف بدون حذف نقشه‌ها:

```sh
node ~/.local/share/mycel/mycel.mjs stop
```

داده‌ها در پوشه `.mycel/` کنار برنامه هستند. نسخه نصب‌شده پین شده است؛ برای ارتقا خودکار git pull نزن، چون نسخه جدید upstream نام و قابلیت‌های متفاوتی دارد.
